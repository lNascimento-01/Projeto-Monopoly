# 🎲 Monopoly Pro
## 📌 Apresentação

O **Monopoly Pro** foi desenvolvido inspirado no clássico jogo Monopoly, utilizando Python.  
O projeto aplica conceitos de aritmética financeira como:

- Soma
- Subtração
- Porcentagem

Além disso, utiliza estruturas avançadas como:

- Programação Orientada a Objetos (POO)
- Estrutura modular
- Sistema de regras
- Eventos dinâmicos

---

## 🧠 Conceitos Aplicados

- Sistema de jogadores estruturados  
- Propriedades com dados completos  
- Aluguel progressivo  
- Eventos aleatórios (tipo cartas)  
- Sistema de falência  
- Código organizado  

---

## 🏗️ Estrutura do Game

### Classes de Propriedades

Cada propriedade contém:

- Nome  
- Preço  
- Aluguel  
- Dono  

---

## 🎮 Mecânica Principal

- Jogador joga o dado  
- Anda no tabuleiro  
- Interage com a casa  
- Compra propriedades  
- Paga aluguel  
- Enfrenta eventos aleatórios  
- Pode falir  

---

## 📖 Descrição do Projeto

Este projeto consiste em um jogo inspirado no clássico Monopoly, desenvolvido em Python para rodar no terminal.

O objetivo é simular decisões financeiras de forma interativa, onde os jogadores podem:

- Comprar propriedades  
- Pagar aluguel  
- Enfrentar eventos aleatórios  
- Administrar seu dinheiro ao longo das rodadas  

O jogo foi criado com foco em:

- Aritmética  
- Lógica de programação  
- Organização de código
